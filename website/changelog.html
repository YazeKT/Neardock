What’s changed.

Neardock 1.0.0 · 3 October 2026

The first Neardock release, designed and maintained by Yaze Media.

A home for your nearby devices

  • A consistent ink-and-orange Windows and Android interface, with a stationary N logo.
  • Send, Receive, Chat, Clipboard and compact searchable Settings.
  • Local conversations with optional history, and explicit clipboard Paste, Copy and Send.
  • Remembered device identities, properties and revocable encrypted-device trust.
  • Fewer repeated acceptance prompts, cancellation guards and text saved only after acceptance.
  • A short first-run welcome, redacted diagnostics and prominent About artwork.
  • Optional GitHub update checks and explicit, SHA-256-verified downloads.
  • Separate Neardock application and settings identities.

Distribution and documentation

Unsigned Windows x64 installer and portable packages, and a signed Android ARM64 APK. Other architectures appear only when their builds are verified. The website includes real screenshots, installation help, privacy information and checked download metadata.

Local builds, analysis and automated app checks passed. The owner accepted the current app for publication; detailed device-transfer and installer lifecycle checks remain recorded separately in the verification report.
