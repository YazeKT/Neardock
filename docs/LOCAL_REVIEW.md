# Local review before GitHub publication

The owner accepted the current application and authorised GitHub publication on 3 October 2026. The review checklist below remains available for detailed follow-up; unrecorded cases are not considered passed. See VERIFICATION.md.

## Phone and Windows review

1. Open Neardock on both devices, connected to the same trusted Wi-Fi network. Stop LocalSend first if it is listening on the default port.
2. Check the stationary orange N, Neardock name, Yaze Media About information and all grouped Settings categories. Review Send, Receive, Chat and Clipboard.
3. Send a small file from Windows to Android, accepting the request on the phone. Open the received file.
4. Send a file back from Android to Windows. Then try a message and several files together.
5. Check Android file selection, destination permission and sharing to Neardock from another app.
6. Reject one transfer and cancel another; verify that subsequent transfers still work.
7. Close and reopen Neardock and confirm settings remain.
8. Test interoperability by running Neardock on one device and LocalSend on the other. Avoid running both servers on the same device at the same port.
