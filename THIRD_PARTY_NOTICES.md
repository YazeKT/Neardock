# Third-party dependencies

The original LICENSE, package licences, vendored cargokit licence, and upstream
copyright notices are retained. Flutter's in-app License Notices screen retains
the dependency licence registry generated by Flutter. The About screen retains
upstream author, contributor and translator credit.

Dart dependencies are pinned in pubspec.lock; Rust dependencies in Cargo.lock.
Review these and the installed package licence files when changing dependencies.
Major components include Flutter/Dart (BSD-style licences), Rust, LocalSend
(Apache 2.0), flutter_rust_bridge (MIT), Refena (MIT), and the Flutter plugins
enumerated by pubspec.yaml. This document is an index, not a replacement for their
individual licence texts. Windows packages include this index and NOTICE.md.

Neardock's asset generation helper uses Pillow; it is a development tool, not an
app runtime dependency.

## Website typography

Space Grotesk is self-hosted in website/assets/fonts/ under the SIL Open Font License 1.1. Its full upstream licence and copyright notice are retained in website/assets/fonts/OFL.txt. No font service is contacted by the website.
