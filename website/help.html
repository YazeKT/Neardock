Your first transfer.

Start with two devices on the same trusted network.

Install on Windows

Run the installer, or extract the complete portable ZIP into a writable folder and open neardock.exe. Allow the app through Windows Firewall on your private network. Portable settings stay in settings.json next to the app.

Install on Android

Download the APK for your phone’s architecture, open it and allow installation from that source if prompted. Restore your preferred installation permission afterwards. Grant the app’s requested discovery and storage permissions.

Send a file or message

  1. Open Neardock on both devices.
  2. Choose the receiving device and add files in Send, then press Send.
  3. Accept the transfer on the receiving device.
  4. Check the selected save destination.

Chat and Clipboard

Use Chat for device conversations. Clipboard lets you manually paste, review, send and copy text. Incoming text appears in both views; Neardock never automatically reads or replaces your clipboard. Text transfers retain the existing receiver confirmation flow. Conversation history is saved locally by default and can be disabled or cleared in Chat & Clipboard settings.

Can’t see the other device?

Check that both devices share a network. Guest Wi-Fi isolation, VPNs, missing permissions and firewall rules can prevent discovery. The default local port is 53317 for TCP and UDP.

Can I use a hotspot or mobile data?

A compatible phone hotspot can create a local network for nearby devices; client isolation may prevent discovery. Ethernet and Wi-Fi devices can share when connected to the same reachable LAN. Sending between separate networks over mobile data is not enabled in this release.

Using LocalSend too?

Both products can be installed. Close one before running the other on the same device because they retain the same default network port. Neardock’s settings and app identity are separate.

Windows Share integration

The optional helper is unsigned and its registration may require developer mode or package trust. Normal transfers work independently of that helper. See the release’s verification notes for tested integration status.

Need more help?

Open a Neardock issue with your app version, OS and steps to reproduce the problem. Remove personal information from logs.
