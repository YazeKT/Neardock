Before you install

Windows builds are unsigned. Android release APKs use Neardock’s own signing key.

Build verification and physical-device testing are recorded separately for each download.

Most recent Android phones use ARM64. Most Intel and AMD Windows PCs use x64.

Installation help →

Check your download

Compare the file’s SHA-256 value with SHA256SUMS.txt in the release. On Windows, use Get-FileHash -Algorithm SHA256.

Install future Android updates over Neardock using an APK signed with the same key. Keep portable settings.json beside the Windows executable.
