# Contributing to Neardock

Open an issue in YazeKT/Neardock to discuss a bug or proposed feature. Include OS,
app version, reproducible steps, and expected behaviour. Remove personal paths,
addresses, tokens, file contents, and device identifiers from logs before sharing.

Use the pinned toolchains and checks in docs/DEVELOPMENT.md. Preserve protocol
compatibility and test both Windows and Android for cross-platform changes.
Keep generated-code changes intentional and preserve upstream notices.
Submit pull requests to the neardock branch. Explain the user-visible change and
the checks performed. AI-assisted contributions are welcome when the contributor
reviews them and provides accountable validation. LocalSend's own contribution
policy still applies to work submitted to its upstream repository.
