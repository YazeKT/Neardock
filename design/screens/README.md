## Design brief

Neardock by Yaze Media, for Windows and Android. Use ink #17191E, charcoal surfaces, warm white text, and orange #F97316. Keep the geometric N upright and stationary. Use clear navigation with separate Send, Receive, Chat, and Clipboard destinations. Chat is for conversations; Clipboard is for manually sharing copy-and-paste text. Group settings into understandable categories with readable descriptions.

Show Yaze Media as the product owner. Retain upstream acknowledgements in the appropriate legal view. Reflect the chosen licensing direction: Apache 2.0 for Neardock code with Yaze Media copyright, and separate terms for brand assets. These mockups do not change the actual source licences or notices.

Use neutral example devices and files. The sheets are image-generated explorations; text, values, controls, and proposed flows require review before implementation. Proposed Chat and Clipboard features and supporting flows are not proof of working app functionality.

No app implementation or GitHub publication is included in this mockup pass. Continue development only after the user resumes the project and reviews the design.
