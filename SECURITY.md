# Security

Supported Neardock targets: Windows and Android. Before a verified release is
published, the source and build artifacts should be treated as under verification.

Report vulnerabilities using GitHub private vulnerability reporting in
YazeKT/Neardock's Security tab. Do not post exploit details or sensitive logs in
public issues. If private reporting is unavailable, open a minimal public issue
requesting a private contact route without disclosing the vulnerability.

Local transfers use the retained LocalSend protocol and security implementation.
Use trusted networks, verify the recipient, and retain transfer confirmation.
No security certification or audit is claimed. Signing keys must stay outside Git.
